# Visual Heights Media

A responsive portfolio experience for Visual Heights Media, an independent film and creative studio. The site combines cinematic art direction with a custom interactive interface for presenting services, selected work, and the artist behind the studio.

## Highlights

- Interactive artist card with layered imagery, light effects, and motion
- Expandable service panels for Motion, Stills, and Interface Systems
- Smooth custom transitions and scroll behavior
- Responsive layouts for desktop and mobile
- Ambient audio controls and custom visual identity treatment

## Built with

- React
- TypeScript
- CSS
- Vinext / Vite

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
